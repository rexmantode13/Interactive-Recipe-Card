# Kasturba Restaurant — 🍽️
Interactive Recipe Collection

A responsive, pixel-perfect, and interactive recipe collection built for Kasturba Restaurant. It showcases recipes with a step-by-step interactive cooking flow, integrated kitchen timers, dynamic progress indicators, and ingredients checklist.

## Features
- **Modern Minimalist Theme**: Warm linen colors and elegant typography designed for a high-end luxury feel.
- **Responsive Layout**: Engineered to look stunning on all device sizes (mobile, tablet, iPhone, Android, and desktop) with zero horizontal scrolling.
- **Interactive Cooking Mode**: Step-by-step instruction checklist highlighting the active step with a custom visual focus.
- **Built-in Timers**: Integrated timers matching specific recipe baking and cooking times.
- **Print Optimization**: Clean, print-friendly stylesheet for users who prefer cooking with physical recipe printouts.

## Technologies Used
- HTML5 (Semantic Structure)
- Vanilla CSS3 (Custom Variables & CSS Grid/Flexbox)
- Vanilla JavaScript (Interactive Cooking Logic)
